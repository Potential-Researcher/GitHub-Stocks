# Every show you've watched together, one per line.
#
# Import it with:   python scripts/watchlist.py import our_shows.example.txt
#
# The only required part is the title. Everything after it is optional:
#
#   Title | your score | her score | status | note
#
# Scores run 1-10. Status is one of: finished, watching, paused, abandoned
# (leave it out and the show counts as finished). The note is free text --
# a line about why it landed or didn't is what makes the list worth keeping.
#
# Don't agonise over exact numbers on old shows. A rough score you can
# revise later beats a blank, and `stats` only needs the shape of your taste.
#
# Delete these examples and put your own list underneath.
